# Lower-Youtube-preview-volume
Youtube previews are too goddamn loud and the volume is not settable, so I fixed it.

Use this script with TamperMonkey:
https://greasyfork.org/en/scripts/577264-lower-youtube-preview-volume

# Functionalities
- Set the volume of the previews to don't get your ears blated;
- Toggle whether previews should be forcefully unmuted.
